# نظام الأكواد والدعم (مجاني) — Cloudflare Worker

التطبيق **مقفول**: أول شيء يطلبه كود دخول تصنعه أنت لشخص معيّن ولمدة تحددها (ساعات، أيام، أشهر، سنوات).
عند انتهاء المدة يُقفل التطبيق ويوقف الخدمة الخلفية. تقارير الأخطاء تصلك على ديسكورد فقط (وصف + معلومات التواصل + ملف اللوق)،
والمستخدم لا يستطيع حفظ اللوق ولا رؤيته. رابط الويب هوك **لا يوجد داخل التطبيق** أبداً، فقط داخل الـ Worker.

## الإعداد (مرة واحدة)
1. حساب مجاني على https://dash.cloudflare.com ثم **Workers & Pages → Create → Create Worker** → **Deploy**.
2. **Edit code**: احذف كل شيء والصق محتوى `support/worker.js` → **Deploy**.
3. **Settings → Variables and Secrets** (النوع **Secret**، واختر Deploy بعد الإضافة):
   - `SECRET`: نص عشوائي طويل (يوقّع الأكواد).
   - `ADMIN_KEY`: كلمة سر صفحة إنشاء الأكواد.
   - `WEBHOOK_URL`: رابط ويب هوك ديسكورد (الجديد).
   - `REVOKED` (اختياري): معرّفات أكواد لإيقافها فوراً، مفصولة بفواصل.

## لوحة التحكم (مهم): ربط KV
1. في Cloudflare: **Storage & Databases → KV → Create** (اسمه أي شيء، مثلاً `fyocord-codes`).
2. افتح الـ Worker → **Settings → Bindings → Add → KV namespace** → اسم المتغير **`CODES`** (حروف كبيرة) → اختر الـ namespace → **Deploy**.
3. افتح رابط الـ Worker → أدخل `ADMIN_KEY` → تظهر اللوحة.

## إنشاء كود لشخص
- اكتب الاسم، **عدد الأجهزة المسموحة**، واختر **تاريخ ووقت الانتهاء بالضبط** (أو اضغط +1h / +1d / +30d ...). يظهر لك الوقت الذي سينتهي فيه بتوقيت جهازك قبل الإنشاء.
- زر **نسخ** ثم أرسل الكود للشخص.

## من اللوحة نفسها
- **إيقاف / تشغيل**: يوقف الكود مؤقتاً ويقفل التطبيق عند صاحبه (خلال نصف ساعة تقريباً مع الإنترنت).
- **حذف**: يلغي الكود نهائياً.
- **تغيير الوقت**: تمديد أو تقصير الوقت لاحقاً (بصيغة `2027-01-31 18:00`).
- **عدد الأجهزة**: تغييره في أي وقت. الجهاز الجديد فوق الحد يُرفض برسالة "الحد الأقصى للأجهزة".
- **مسح الأجهزة / x**: يحرر مكاناً لجهاز جديد. تظهر لكل جهاز: الموديل، أول مرة، آخر ظهور.

بدون KV تعمل صفحة بسيطة قديمة (الوقت داخل الكود، وإيقاف عبر `REVOKED`) بدون حذف ولا حد أجهزة.

## ملاحظات
- لا تحاول الأجهزة تغيير الوقت للتمديد: إذا رُجع الوقت للخلف يُقفل التطبيق حتى يعود الوقت صحيحاً.
- اللوق يُنظَّف قبل الإرسال (روابط بلا باراميترات، توكنات، أرقام معرّفات، إيميلات) ولا تُرسل محتويات الرسائل المسجّلة.
- الحدود: 10 طلبات بالدقيقة لكل كود/عنوان، وحجم التقرير حتى 1MB.
