# إعداد نظام الدعم (مجاني) — Cloudflare Worker

الفكرة: التطبيق **لا يحتوي** رابط الويب هوك أبداً. الرابط يبقى سرّاً داخل Worker، والمستخدم يدخل **كوداً مؤقتاً**
تنشئه أنت، وعند الإرسال يصل لك على ديسكورد: وصف المشكلة + معلومات التواصل + ملف اللوق.

## الخطوات (من الموبايل أو الكمبيوتر)
1. أنشئ حساباً مجانياً على https://dash.cloudflare.com
2. من القائمة: **Workers & Pages → Create → Create Worker** → سمّه مثلاً `fyocord-support` → **Deploy**.
3. اضغط **Edit code**، احذف الكود الموجود والصق محتوى الملف `support/worker.js` كاملاً → **Deploy**.
4. من **Settings → Variables and Secrets → Add** (النوع **Secret**) أضف ثلاثة أسرار:
   - `SECRET` : أي نص عشوائي طويل (يوقّع الأكواد).
   - `ADMIN_KEY` : كلمة سر تدخلها في صفحة إنشاء الأكواد.
   - `WEBHOOK_URL` : رابط ويب هوك ديسكورد (الرابط **الجديد** بعد إعادة إنشائه).
5. افتح رابط الـ Worker (يشبه `https://fyocord-support.اسمك.workers.dev`)، أدخل `ADMIN_KEY` ومدة الصلاحية (بالساعات)
   → يظهر الكود. أرسله للمستخدم؛ هو يلصقه في: الزر العائم → **Report** → *Support code*.

## ملاحظات
- الكود ينتهي تلقائياً بعد المدة (حد أقصى 72 ساعة). لإلغاء كل الأكواد الحالية غيّر قيمة `SECRET`.
- اللوق يُنظَّف قبل الإرسال (روابط بلا باراميترات، توكنات، أرقام معرّفات، إيميلات)، ولا تُرسل محتويات الرسائل المسجّلة.
- الحدود: 5 تقارير بالدقيقة لكل كود/عنوان، وحجم التقرير حتى 1MB.
