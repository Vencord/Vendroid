# Vendroid

Vendroid is a custom Discord client for Android that uses the same Discord web app as desktop.

Discord's web site is pretty bad and slow on mobile, so you should probably use a [proper mobile mod](https://vencord.dev/support/#Is-there-a-mobile-version-of-Vencord?) instead
